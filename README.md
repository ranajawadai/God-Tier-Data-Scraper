## 🛠️ Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/yourusername/ultimate-scraper-pro.git
   cd ultimate-scraper-pro
   ```

2. **Run Installer (Windows)**
   Double-click `setup_pro.bat`.

   *OR Manual Install:*
   ```bash
   pip install -r requirements_pro.txt
   python backend_pro.py
   ```

3. **Open Dashboard**
   The tool will automatically launch at `http://localhost:8000`.

## 📖 Usage Guide

1. Enter your target keyword (e.g., "Gyms in New York").
2. Select your platform (Google Maps recommended for best results).
3. Click **START ENGINE**.
4. Watch the live logs and export your data when done!
